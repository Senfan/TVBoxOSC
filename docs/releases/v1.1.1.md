# TVBox v1.1.1

首次固定正式签名发行，versionCode **6**。

## 发布渠道

- 通用 normal（Java）版，ARM64 / `arm64-v8a`。
- 包名：`com.github.tvbox.osc.tk`，最低 Android API 21。
- APK：`TVBox-release-code6-arm64-generic.apk`。
- 固定正式证书 SHA-256：`c9d4035688a13f886e6661edc3631f8da38bf84e8676c2c4ade87c00f66bd821`。

## 本版改进

- 应用内手动检查更新，独立可配置更新地址；HTTPS 下载、大小与 SHA-256 校验、APK 包名/渠道/版本/签名预检，交给系统确认安装。
- 安装成功后根据实际已安装版本回收更新包和已废弃的更新临时文件；启动兜底重试清理。取消安装、活跃下载与系统安装器持有的文件受到保护。
- 播放器临时回退：仅当前播放轮次切换，不自动覆盖保存的影片或全局偏好，显示实际临时播放器。
- 直播频道可独立选择播放器、跟随直播默认或重置覆盖；保留频道画面比例等设置。
- 弹幕默认关闭，改进后台加载、异常条目及播放生命周期处理。
- 调整全局设置、播放器标签、首页标题及遥控焦点呈现。

## 安装与更新

正式版与此前 `1.1.0-debug` / code5 的 Android Debug 签名不同，**不能直接覆盖调试包**；提高版本号也不能解决异签名问题。不要卸载或清数据来冒充无损升级验收。正式更新应保持同包名、同渠道、同固定密钥，并递增 versionCode。

正式发行的稳定更新清单地址：

```text
https://github.com/Senfan/TVBoxOSC/releases/latest/download/update-manifest.json
```

链接只有 GitHub 正式 Release 发布完成后才生效；APK、清单与校验值必须来自最终发布提交的实际产物。保存更新地址不会自动联网或安装。
