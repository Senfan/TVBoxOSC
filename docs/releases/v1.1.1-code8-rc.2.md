# TVBox v1.1.1-code8-rc.2 — Sony ABI兼容预发布

**Pre-release，非稳定版，不设为 Latest。不是全依赖/原生库最新版，也未完成 Sony XR-75X90K 真机功能验收。**

## 为什么增加rc.2

rc.1只提供`arm64-v8a`，Sony电视安装时明确提示不兼容；用户核对此前可安装包名含`armeabi`。电视芯片可能是64位，但其Android应用环境可能只接受32位ARM应用。因此本版递增到versionCode **8**，同时提供两个独立APK：

- `TVBox-code8-armeabi-v7a-generic-normal-rc2.apk`：Sony目标包。
- `TVBox-code8-arm64-v8a-generic-normal-rc2.apk`：保留给真正支持64位应用的设备。

每个APK只包含一种ABI，避免fat APK增加体积和混淆渠道。统一`update-manifest.json`包含两条记录，应用按自身ABI匹配。

## 安装包身份

- 应用内版本：1.1.1（versionCode 8）。标签rc.2只表示预发布轮次。
- 包名：`com.github.tvbox.osc.tk`；渠道：generic / normal。
- minSdk21、targetSdk34、compileSdk37，R8混淆Release，非debuggable。
- 固定生产证书SHA256：`c9d4035688a13f886e6661edc3631f8da38bf84e8676c2c4ade87c00f66bd821`；两个APK均验证v1/v2签名。
- 实际大小、SHA256、ELF数量和源码提交见随附`build-info.json`与`SHA256SUMS`。

- Sony实际Android API/固件、完整SAF、影片播放、HDR、音频直通、PiP/媒体FGS实播仍未验证。
- IJK/FFmpeg和QuickJS仍是旧定制native，仓库缺对应源码；迅雷/P2P缺可信新版成套SDK。没有用未知二进制替换或删除功能。
- 最新min23/24依赖仍受Sony实际系统门禁，不能称所有依赖最新。
- armeabi-v7a构建成功和ELF正确只证明APK架构，不替代电视安装与运行结果。
