# 播放器回退回归验证

## 无 Android 依赖的测试

使用 JDK 11 或更新版本，从项目根目录执行：

```bash
bash tests/run-playback-retry-tests.sh
```

测试在临时目录编译策略与成功观察类，结束后清理 class 文件，不修改影片历史或全局设置。

覆盖范围：
- 获取信息、解析、嗅探错误不切播放器。
- 原选择先尝试，失败后按 IJK、EXO、系统、Ali、已安装 MX/Reex/Kodi 的顺序去重遍历。
- 每个地址每种播放器最多尝试一次；新地址独立，同地址内部 refetch 不补充预算，信息重取最多一次。
- 成功只清除策略的临时调度选择，不清空已尝试集合或信息重取预算；之后报错仍尝试剩余播放器。新播放轮次重新采用调用者原偏好。
- 两播放入口的成功回调静态保护：只标记策略成功，不写影片配置、不发偏好事件、不清除实际播放器显示；手动保存路径保留。此检查限定回调方法范围，不等价于 Android 运行或数据库验证。
- 缺少外部播放器、无地址、DASH 强制 EXO、手动重置、耗尽。
- 成功观察需约 5 秒正常播放，准备、暂停、缓冲、卡住、seek、初始缓存进度、倍速变化不误算成功。
- 短片自然结束需至少两个真实推进区间；seek 到片尾不能算成功。

## 直播播放器偏好回归

```bash
bash tests/run-live-player-tests.sh
```

直接编译真实 `LivePlayerManager`，Hawk、VideoView、PlayerHelper 使用最小测试替身。
JSON 使用本地 Gradle 缓存中的 `org.json:json:20180813`；也可用 `JSON_JAR` 指定本地 JVM jar。
脚本不联网、不写真实应用数据，在临时目录编译并清理 class 文件。

覆盖频道独立选择、四种解码映射、默认优先级、只改比例不形成播放器覆盖、当前台跟随默认、全部重置保留默认及比例、旧播放器不复活、重新初始化、缓存复制和保存失败。
旧频道缓存无法判断播放器是否曾手动选择，未重置前保守兼容；全部重置后忽略旧 `pl/ijk`，仍保留比例等字段。

设备验收：
- 直播“频道播放器”前四项只针对当前频道；A/B 台可用不同播放器。
- “设为直播默认”只影响跟随默认的频道，不覆盖其他频道明确选择。
- “当前频道跟随默认”立即应用默认，保留该台画面比例。
- “重置全部频道播放器”取消／返回不改设置；确认后所有频道跟随默认，重进直播仍有效。
- 重置保留直播默认、比例、收藏与点播设置；重置后可重新为特殊频道设独立播放器。
- 同一引擎点击不重启，实际切核保留 URL／请求头；确认弹窗默认聚焦取消，菜单焦点与选中高亮正常。

## Android 构建

当前 nextlib 依赖含 Java 17 字节码，完整应用构建需使用 JDK 17。配置 `JAVA_HOME` 后执行：

```bash
bash gradlew :app:assembleArm64GenericNormalDebug
```

## 设备验收

构建和纯策略测试不能替代以下运行验收：
- 未配置数据源时，本地播放及解码菜单使用内置软／硬解码选项，不空指针、不改全局偏好；之后加载数据源仍能采用其自定义 IJK 配置。
- 全局 IJK＋优先全局设置；未保存配置的影片采用该默认。
- 初始播放器失败后逐个尝试；内置启动约 30 秒无真实推进才触发启动超时（不是解析/嗅探超时）。暂停／后台不消耗该时间。
- 自动回退失败或成功都不保存播放器选择；成功前后调整倍速／片头仍保存原 `pl`，不夹带临时播放器，不修改全局和其他影片。
- 回退成功后控制栏仍显示真实播放器及“临时”标签（名称不隐藏、按钮随文字展开）；重开同片采用原影片配置，缺失时采用全局／来源默认。同一剧共用影片配置，切集开始新轮次。
- 同地址和候选地址切核保留 URL、请求头与失败前进度；显式重播和换集清除临时恢复位置。
- 播放信息迟到／旧播放器回调、换片、销毁不能触发错误轮次或重复重试。
- 未安装外部跳过；启动失败继续；外部回退打开后返回出现一次“成功，仅本次／失败试下一个／取消”确认。三种结果均不保存播放器选择，返回键等于取消。
- 手动选择仍立即保存；已经保存的外部播放器正常打开时不额外要求确认。外部 App 是否支持进度恢复不作保证。
- 内部 DASH／MPD 保持 EXO 约束，不把协议强制改为影片偏好；保留已有手动外部路径。
- 全局弹幕关闭后换集、换片、重启和调整样式仍关闭；开启对齐当前进度，暂停和画中画正确处理。
- 两播放入口（Activity 和预览 Fragment）、遥控器焦点、短片自然结束、画中画退出均检查。

旧影片历史不批量改写，不删除播放进度；此前保存成 EXO 的影片可以手动选择 IJK。自动回退即使成功，也不会改写原保存选项。

## 本地实播记录（2026-11-05）

ARM64 TV 模拟器，未配置数据源，从文件入口进入 `PlayActivity`：
- 系统播放器播放 MPEG4／MP3 AVI 报错后，自动回退 IJK，视频真实推进超过一分钟，不再触发 `ApiConfig.getIJKCodec` 空指针。
- 回退成功后控制栏显示 `IJK（临时）`，影片播放器菜单仍勾选 `系统`。
- 调整倍速到 1.25、设置片头后，菜单仍勾选 `系统`，没有夹带临时播放器。
- 手动选择 IJK 后，当前影片菜单改为勾选 IJK，控制栏不再标记临时。
- 自动回退、其他播放参数调整及手动影片选择期间，Hawk 偏好文件摘要保持一致；结束后全局设置仍为 `系统`／`优先全局设置`／`弹幕关闭`。
- 再次打开本地视频重新采用全局系统播放器，失败后仍临时回退。仅移除本次添加的存储快捷入口，测试视频保留。

本记录不等价于普通影片 Room 历史验证：文件入口的影片配置不经过普通详情页历史链路。预览 Fragment、普通影片重开／切集、外部播放器确认，以及本地播放后加载自定义数据源 IJK 配置，尚未完成设备实测。
